# AeroGrid — Вітрова електростанція з моніторингом швидкості вітру

Мобільний застосунок на базі операційної системи Android для диспетчерського моніторингу та інженерного розрахунку параметрів промислової вітрової електростанції (ВЕС).

## Загальна інформація

* **Дисципліна:** Розробка програмного забезпечення мобільних пристроїв
* **Університет:** Національний технічний університет України «Київський політехнічний інститут імені Ігоря Сікорського»
* **Кафедра:** Кафедра інженерії програмного забезпечення в енергетиці
* **Практичні роботи:** Комплексне виконання завдань №1–4
* **Варіант:** №2 («Вітрова електростанція з моніторингом швидкості вітру»)

## Функціональність

Застосунок розроблено на основі архітектури з єдиною активністю (Single-Activity) та нижньою панеллю навігації, яка об'єднує модулі практичних занять:

1. **Оперативний моніторинг (ПЗ №1):**
   * Відображення поточної сумарної генерації вітропарку в мегаватах (МВт).
   * Програмна візуалізація трилопатевої вітрової турбіни через декларативний Jetpack Compose Canvas (без використання растрових графічних файлів).
   * Динамічна анімація кутової швидкості обертання ротора у відповідності до поточної швидкості вітру.
   * Інтерактивна симуляція поривів вітру (діапазон 0–30 м/с) та швидкі режими: Штиль (1.5 м/с), Бриз (7.0 м/с), Номінал (12.5 м/с), Шторм (27.0 м/с).

2. **Аеродинамічний калькулятор (ПЗ №2):**
   * Інженерне моделювання за фізичним законом Беца:
     P = 0.5 * rho * S * v^3 * Cp
     де rho = 1.225 кг/м^3 (густина повітря), S = pi * R^2 (площа ометання ротора), v — швидкість вітру, Cp — аеродинамічний коефіцієнт (обмежений теоретичною межею Беца 59.3%).
   * Інтерактивні поля введення параметрів та швидкі конфігурації промислових генераторів (2.0 МВт, 3.4 МВт, 5.0 МВт).
   * Розрахунок площі ометання ротора, активної виробленої потужності (кВт, МВт) та добового виробітку електроенергії (МВт*год).
   * Винесення бізнес-логіки в окремий модуль з покриттям автоматизованими модульними тестами (JUnit 4).

3. **Керування парком турбін (ПЗ №3):**
   * Моніторинг окремих вітроустановок вітропарку (ВЕС-01 — ВЕС-05).
   * Відображення коефіцієнта завантаження генератора відносно паспортного номіналу через лінійні індикатори.
   * Контроль телеметричних параметрів: поточної швидкості вітру, кутової швидкості ротора (об/хв) та кута установки лопатей (Pitch-контроль).
   * Диференціація експлуатаційних статусів: генерація в мережу, очікування вітру (Cut-in), аварійне гальмування при бурі (Cut-out > 25 м/с), технічне обслуговування.

4. **Кабінет диспетчера та авторизація (ПЗ №4):**
   * Модуль авторизації та реєстрації оперативного інженерного персоналу станції.
   * Клієнтська валідація полів: перевірка на непорожність, валідація формату електронної пошти, мінімальної довжини та збігу паролів.
   * Маскування введення конфіденційних даних через PasswordVisualTransformation.
   * Індикація процесу обробки через CircularProgressIndicator.
   * Відображення робочого кабінету чергового інженера зміни з інформацією про права доступу SCADA та параметри захищеного з'єднання.

## Технологічний стек

* **Мова програмування:** Kotlin 2.2.10
* **Середовище розробки:** Android Studio
* **Мінімальна версія SDK:** Android 7.0 (API 24)
* **Цільова версія SDK:** Android 15 (API 37)
* **UI Toolkit:** Jetpack Compose, Material Design 3
* **Система збірки:** Gradle (Kotlin DSL, Version Catalogs)
* **Тестування:** JUnit 4

## Структура проєкту

```
app/src/main/java/ua/kpi/windpower/
├── MainActivity.kt                      // Головна точка входу з Scaffold та NavigationBar
├── data/
│   ├── TurbineModel.kt                  // Моделі даних вітрових турбін та статуси SCADA

│   │   ├── DashboardScreen.kt           // Екран оперативного моніторингу вітропарку
│   │   ├── CalculatorScreen.kt          // Екран аеродинамічного калькулятора
│   │   ├── TurbineFleetScreen.kt        // Екран моніторингу парку турбін
│   │   └── AuthProfileScreen.kt         // Екран авторизації та кабінету диспетчера
│   └── theme/
│       ├── Color.kt                     // Кольорова палітра теми

    └── WindPowerCalculatorTest.kt       // Модульні тести для перевірки розрахунків
```

## Інструкція зі збірки та запуску

1. Клонувати репозиторій:
```bash
git clone https://github.com/DmytroHnylytskyi/rpzmp_LR1.git
```

2. Відкрити проєкт в Android Studio.

3. Дочекатися завершення автоматичної синхронізації залежностей Gradle.

4. Запустити модульні тести:
```bash
./gradlew testDebugUnitTest
```

5. Зібрати та встановити Debug APK на підключений пристрій або емулятор:
```bash
./gradlew installDebug
```
