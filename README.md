# AeroGrid — Вітрова електростанція з моніторингом швидкості вітру

Мобільний застосунок на Android для диспетчерського моніторингу та інженерного розрахунку параметрів промислової вітрової електростанції (ВЕС).

## Загальна інформація

* **Дисципліна:** Розробка програмного забезпечення мобільних пристроїв
* **Університет:** Національний технічний університет України «Київський політехнічний інститут імені Ігоря Сікорського»
* **Кафедра:** Кафедра інженерії програмного забезпечення в енергетиці
* **Практична робота:** №1 (завдання №1–4)
* **Варіант:** №2 — «Вітрова електростанція з моніторингом швидкості вітру»

## Можливості застосунку

Застосунок побудований за Single-Activity архітектурою на Jetpack Compose з нижньою панеллю навігації та складається з чотирьох модулів.

### Оперативний моніторинг

* Сумарна генерація парку в мегаватах, розрахована за паспортними даними кожної установки (спільне джерело даних `TurbineFleet`).
* Декларативна візуалізація трилопатевої турбіни через Jetpack Compose Canvas без растрових графічних файлів; швидкість обертання ротора синхронізована з поточною швидкістю вітру.
* Симуляція швидкості вітру (0–30 м/с) та швидкі метеопресети: Штиль (1.5), Бриз (7.0), Номінал (12.5), Шторм (27.0) м/с.
* Автоматичні експлуатаційні режими за порогами Cut-in (3.0 м/с) та Cut-out (25.0 м/с) з колірною індикацією статусу.

### Аеродинамічний калькулятор

* Розрахунок за законом Беца: `P = ½ · ρ · S · v³ · Cp`, де ρ = 1.225 кг/м³, S = πR².
* Валідація вхідних параметрів: робочий діапазон вітру 3.0–25.0 м/с, коефіцієнт Cp не перевищує теоретичну межу 59.3%.
* Результати: потужність у кВт та МВт, площа ометання ротора, добовий виробіток (МВт·год).
* Типові конфігурації промислових ВЕУ (2.0, 3.4, 5.0 МВт) як швидкі пресети.

### Керування парком турбін

* Диспетчерський список агрегатів (ВЕС-01 — ВЕС-05+) з повним життєвим циклом: додавання нових турбін, редагування паспортних даних (модель, номінальна потужність, довжина лопаті, режим технічного обслуговування) та видалення з діалогом підтвердження.
* Для кожної установки: чіп експлуатаційного статусу (генерація, очікування вітру, оптимізація кута атаки, аварійне гальмування, ТО), індикатор завантаження відносно номіналу та телеметрія (вітер, оберти ротора, Pitch-кут).
* Зміна складу парку миттєво перераховує телеметрію та сумарну генерацію на головному екрані.

### Кабінет диспетчера та авторизація

* Вхід на зміну доступний лише зареєстрованому персоналу: форми входу та реєстрації з перевіркою облікових записів у реєстрі.
* Паролі зберігаються виключно у вигляді SHA-256 хешів (`Validators.sha256`).
* Валідація полів: формат корпоративного email, довжина пароля (від 6 символів), збіг паролів, унікальність Email/позивного; розмежовані повідомлення «обліковий запис не знайдено» та «невірний пароль».
* Кабінет чергового інженера: ПІБ, роль, статус сесії, рівень доступа SCADA, параметри захищеного каналу зв'язку.

Демонстраційний обліковий запис: логін `dispatcher`, пароль `Wind2026`.

## Технології

* **Мова:** Kotlin 2.2.10
* **Платформа:** Android (minSdk 24, targetSdk 37)
* **UI:** Jetpack Compose (BOM 2026.02.01), Material Design 3, темна тема Eco-Tech
* **Тестування:** JUnit 4 (`WindPowerCalculatorTest`, `DispatcherRegistryTest`)

## Збірка та запуск

1. Відкрити проєкт в Android Studio та дочекатися синхронізації Gradle.
2. Запустити модульні тести:
```bash
./gradlew testDebugUnitTest
```
3. Зібрати та встановити застосунок на підключений пристрій або емулятор:
```bash
./gradlew installDebug
```
